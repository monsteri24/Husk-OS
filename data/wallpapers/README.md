# Official Husk OS wallpaper

`husk-desert.jpg` contains the original user-supplied black-and-gold desert
wallpaper, unchanged. The attachment was named `26264.png`, but its actual
format is JPEG (1536 × 864); only the filename extension was corrected.

SHA-256: `e0f2ee190ff6c11a2102251d4fb13f3cad2690a8f3b9ef3bc5e963079aaeeaac`

The image is included at the project owner's request as Husk OS branding.
Its artwork is not attributed to the third-party icon themes used by the UI.
The desktop draws it internally with uniform centered cover scaling and
redraws after allocation changes. A custom path in Settings overrides it;
an empty or unreadable image selection falls back to this default.
