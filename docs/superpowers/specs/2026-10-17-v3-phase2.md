## Design and boundaries

- Retain Python GTK Husk Desktop and Labwc/Wayland, internal ownos aliases,
  wallpaper bytes, native application icons and English-only active UI.
- Use Calamares 3.3.14/KPMCore for partitioning, filesystem copy, users, fstab,
  initramfs and GRUB. Restrict this first installer to explicit whole-drive
  erase on UEFI machines. No alongside, resizing, encryption or custom
  partitioning claims. Preserve Calamares's real disk-change summary and add
  its separate installation confirmation. The Live source must be excluded
  and checked immediately before queued writes; fail closed when identity is
  ambiguous. No real host disk installation tests.
- Keep locale/timezone data in Calamares. Add clickable UTC clock offsets
  covering -12 through +14, including real fractional offsets, with explicit
  IANA region selection and live DST-aware clock display. Retain zoneinfo;
  never install a fixed-offset selection in place of a real region.
- Completion is reachable only after the successful job queue including
  bootloader, unmount and synchronization. Show a 30-second countdown,
  Restart Later on the left and Restart Now on the right. Later cancels the
  timer and exits; all failures disable automatic restart.
- Expose maximized/fullscreen/output state through the existing native
  foreign-toplevel bridge. Panel policy is output-local, clears reservation
  and background when maximized, keeps centered interactive icons, and unmaps
  completely for fullscreen. Restore on all state exits.
- GTK desktop controller supplies real file operations and protected virtual
  Home, Trash and Live-only Install Husk OS. Standard Gio/freedesktop Trash
  supports restore/confirmed empty; hiding its icon only saves show_trash.
- Persist yellow accent `#f5cf3b` through validated ConfigStore; immediate
  native style updates and reset; retain other Appearance settings.
- NetworkManager/libnm supplies Wi-Fi scanning, secure secrets, connect,
  disconnect and diagnostics; Blueman/BlueZ supplies pairing controls.
  Tray order Network, Volume, Bluetooth, Clock. No hardware support promises.
- Application installs check connection, DNS and repositories before asking
  for credentials; graphical progress streams real transaction output.
  Preserve polkit authorization, curated package allowlists, signatures and
  full-upgrade semantics. Passwords never appear in argv or logs.
