# Husk OS V3 Phase 2 Implementation Plan

> Execute independent subsystem tasks with the dispatching-parallel-agents
> skill; root integrates and reviews the complete branch. The user's full
> implementation request authorizes execution without repeated approvals.

**Goal:** deliver a safely installable V3 candidate while preserving System 2.

**Architecture:** retain GTK/Labwc and extend the already configured, pinned
Calamares backend. Keep policy and IO boundaries separately testable.

**Tech Stack:** Python, GTK 3, Gio/libnm, Wayland layer-shell/foreign-toplevel,
C, Calamares/Qt 6, KPMCore, Archiso, QEMU/OVMF.

**Spec:** `docs/superpowers/specs/2026-10-17-v3-phase2.md`.

## Global constraints

English is the only active UI language. Preserve wallpaper/native icons and
System 1/2 releases. Never operate on real disks in tests, remove signature
verification, install optional applications by default, log secrets, or
publish a candidate whose essential installer acceptance is unproven.

## Review focus

1. Live-source aliases, mounted child partitions, device removal/replacement.
2. Fullscreen state on another output or a minimized/background window.
3. Clipboard paths and Trash metadata collisions, protected virtual launchers.
4. DNS loss or authorization cancellation between preflight and transaction.
5. Failed bootloader/sync/unmount and completion timer race with Restart Later.
