# Own Gaming OS MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver buildable Arch gaming-distribution sources and a tested custom desktop MVP.
**Architecture:** Own Python/GTK shell over labwc, an isolated C Wayland bridge, signed Arch packages and an inherited Archiso profile with Calamares desktop selection.
**Tech Stack:** Python 3.12+, GTK3, gtk-layer-shell, Wayland, labwc, Archiso, Calamares 3.3.14, pacman, polkit.
**Spec:** docs/superpowers/specs/2026-10-14-mvp-design.md

## Global Constraints

- No changes to the user's physical machine or partitions.
- `ownos` is a technical working identifier, not the final product name.
- Own Desktop is Experimental and version is 0.1.0-dev.
- No shell execution of desktop Exec fields or arbitrary privileged commands.
- All package transactions retain signature checks and full Arch upgrades.
- ISO/VM/game/driver support may be claimed only after the matching test runs.

## Review Focus

- Malformed or truncated game manifests must not crash desktop startup.
- A malicious package choice must never become an executed command.
- An installer target of `/` or a symlink must not become the install root.
- A missing Wayland bridge or audio/network utility must degrade visibly.
- Selecting KDE, GNOME or Minimal must remove live autologin and root login.
